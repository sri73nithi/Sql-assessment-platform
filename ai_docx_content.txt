AI-Powered SQL Assessment Management System
1. Project Overview
The 
AI-Powered SQL Assessment Management System
 is a web-based platform designed to automate the process of assessing SQL knowledge in educational institutions, corporate training programs, and coding 
bootcamps
. Unlike traditional Learning Management Systems (LMS), this platform does 
not provide learning materials or lessons
. Instead, it focuses entirely on 
evaluating a user's understanding of assigned SQL topics
 through automatically generated assessments.
The platform enables administrators to create assessments by selecting SQL topics, difficulty levels, number of questions, and assessment duration. Using Artificial Intelligence, the system dynamically generates SQL questions based on the selected topics. Students then solve these questions using an integrated SQL editor, and their queries 
are automatically executed, evaluated, and scored
.
Beyond checking whether the output is correct, the AI also 
analyzes
 the quality of the SQL query, including its efficiency, readability, coding standards, and logical correctness. The platform then generates detailed feedback and maintains progress reports for both students 
and
 administrators.
2. Problem Statement
In many organizations and educational institutions, SQL assessments 
are conducted
 manually. Trainers are responsible for preparing questions, evaluating answers, calculating scores, and identifying students' weak areas. This process is time-consuming, inconsistent, and difficult to scale.
Additionally, students often receive only a final score without understanding why their solution was inefficient or incorrect. There is also no systematic way to track progress across different SQL topics.
To overcome these limitations, an automated assessment platform is required that can generate questions, evaluate SQL queries intelligently, provide detailed feedback, and maintain comprehensive performance analytics.
3. Project Objective
The primary objective of this project is to develop an AI-powered platform that automatically validates users' SQL knowledge through intelligent assessments.
The system aims to:
Allow administrators to create SQL assessments by selecting predefined topics. 
Automatically generate SQL questions using Artificial Intelligence. 
Execute submitted SQL queries securely. 
Compare the generated output with expected results. 
Analyze
 query quality using AI. 
Calculate scores automatically. 
Generate detailed performance reports. 
Track individual and overall student progress. 
Export assessment results as CSV reports.

Module 4 – AI Question Generation
This is the core feature of the system.
Based on the selected topics and difficulty level, the AI generates SQL questions dynamically.
Example:
Topic:
 JOINS
Generated Questions:
Display customer names along with the products they purchased. 
Find customers who have never placed an order. 
Display total sales for each product category. 
Retrieve the top five customers based on total purchase amount. 
Display employees who have generated revenue greater than the department average. 
Every assessment can contain different questions while testing the same SQL concepts, minimizing repetition and encouraging conceptual understanding.

SQL editor 
Submit button 
Students write and submit SQL queries directly within the platform.
Module 6 – SQL Execution Engine
Submitted SQL queries 
are executed
 within a secure sandbox database environment.
The system:
Executes the student's query. 
Produces the output. 
Compares the output with the expected result. 
Determines whether the solution is correct. 
This ensures objective and accurate evaluation.

In addition to checking correctness, the AI evaluates the quality of the submitted SQL query.
The AI reviews:
Logical correctness 
Query efficiency 
SQL coding standards 
Readability 
Proper JOIN usage 
Alias usage 
Formatting 
Unnecessary operations
